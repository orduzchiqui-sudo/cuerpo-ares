# Cuerpo Ares

App personal de salud (PWA): calorías y nutrientes por foto con Gemini, sueño, ejercicio y hábitos hormonales.
Los datos se guardan solo en el celular (localStorage). La clave de Gemini la pone cada usuario en Ajustes y nunca está en este repositorio.

Instalar: abrir el sitio en Chrome del celular → menú ⋮ → "Instalar app".
